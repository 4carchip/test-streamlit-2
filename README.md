# ClassMate — 근거 기반 학습 보조 AI

교재 PDF를 올리고 질문하면, **올린 자료에만 근거해서** 설명하고 근거 쪽 번호를 함께 보여 주는 Streamlit 앱입니다.
융합소프트웨어프로젝트 팀 프로젝트 (정해윤, 이윤행)

## 주요 기능

| 페이지 | 기능 |
|---|---|
| 📖 공부하기 | PDF 업로드 → 근거 기반 질의응답 (핵심 설명 / 부연 설명 / 시험 포인트), 근거 쪽 표시, 출제기준 기반 교차 출제 안내 |
| 📝 이해도 확인 | 공부한 범위로 4지선다 문제 생성 → 채점·해설 → 오답노트, 외부 기출 사이트 바로가기 |
| 🔑 멀티AI API 연결 안내 | 학교 멀티AI API 키 설정 방법, 연결 테스트, 오류 해결표 |
| 사이드바 (공통) | **AI 모델 선택**, **교차검증 켜기/끄기(선택)**, **사용량**(호출 수·토큰·비용 추정·예산 막대) |

### 교차검증 (선택 기능)
사이드바에서 켜면, 설명 모델(A)이 만든 답변을 검증 모델(B)이 **근거 문단만 보고** 주장 단위로 판정합니다.
✅ 근거 확인 / ⚠️ 근거 없음 / ❌ 근거와 다름. 퀴즈에서는 B가 직접 풀어 보고 정답이 다르면 "정답 검토 필요"를 표시합니다.
호출이 한 번 더 일어나므로 기본값은 꺼짐입니다.

### 교차 출제 안내
"이 개념은 정보처리기사 필기에도 나온다"는 문장을 AI가 지어내지 않도록, `data/exam_standards/`의 출제기준 데이터를 **검색**해서 보여 줍니다.
팀원이 확인한(`verified=TRUE`) 연결만 단정해서 표시하고, 확인 전인 후보는 "검토 중"으로 따로 보여 줍니다. 자세한 설계는 [`data/exam_standards/README.md`](data/exam_standards/README.md) 참고.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

API 설정 없이 실행하면 **데모 모드**로 동작합니다 (AI를 호출하지 않고 자료 문장으로 화면 흐름만 보여 줌).

## 멀티AI API 설정

1. `.streamlit/secrets.toml.example`을 복사해 `.streamlit/secrets.toml`을 만듭니다.
2. 학교 멀티AI 플랫폼(https://ai.hknu.ac.kr)에서 확인한 **주소(base_url), API 키, 모델 ID**를 채웁니다.
3. Streamlit Cloud에 배포할 때는 앱 **Settings → Secrets**에 같은 내용을 붙여 넣습니다.
4. 앱의 '멀티AI API 연결 안내' 페이지에서 **연결 테스트**를 눌러 확인합니다.

> 예전처럼 `OPENAI_API_KEY`(와 `OPENAI_MODEL`)만 Secrets에 있으면 OpenAI 공식 API로 동작합니다. 멀티AI 설정을 추가하면 그쪽이 우선입니다.
> `secrets.toml`은 `.gitignore`에 들어 있습니다. API 키를 절대 커밋하지 마세요.
> 플랫폼이 OpenAI 호환 형식이 아니라면 `core/llm.py`의 `_call()`만 고치면 됩니다.

## 폴더 구조

```
app.py                      # 진입점: 페이지 등록 + 공통 사이드바
app_pages/
  study.py                  # 공부하기 (질의응답·교차검증·교차 출제 안내)
  quiz.py                   # 이해도 확인 (문제 생성·채점·오답노트·외부 링크)
  api_guide.py              # 멀티AI API 연결 안내·연결 테스트
core/
  config.py                 # secrets 읽기, 모델 목록
  llm.py                    # OpenAI 호환 API 호출, 오류 안내
  usage.py                  # 사용량 기록 (세션 / 앱 누적)
  sidebar.py                # 모델 선택·교차검증·사용량 사이드바
  documents.py              # PDF 텍스트 추출, BM25 검색
  crosscheck.py             # 두 모델 교차검증
  mapping.py                # 출제기준 기반 교차 출제 안내
  state.py                  # 업로드 자료 상태
  demo.py                   # 데모 모드 응답
data/exam_standards/        # 출제기준·개념·연결 CSV
```

## 자료 사용 원칙

- 교재 PDF는 **본인이 구매·소유한 자료**만 올립니다. 업로드한 자료는 브라우저 세션 안에서만 쓰이고 저장소에 올라가지 않습니다.
- 인터넷 강의 영상은 앱에서 다운로드하지 않습니다. 학습자가 직접 시청합니다.
- 기출문제는 앱으로 가져오지 않고 원래 사이트로 **링크만** 연결합니다 (저작권·이용약관).

## 알려진 한계

- 사이드바 사용량은 토큰 수 기반 **추정치**입니다. 정확한 잔여 크레딧은 멀티AI 대시보드에서 확인하세요.
- 스캔본 PDF(이미지)는 텍스트가 추출되지 않습니다.
- 정보처리기사 출제기준의 세부 항목은 아직 확인 전(`verified=FALSE`)입니다. 큐넷 출제기준 문서로 채워야 합니다.
