# 답변 잘림·제목 크기·후속 질문 검색 수정 (2026-11-18)

## 목표 / Goal
사용자가 실제 모델(GPT-6.1 Sol)로 "윈도우 함수가 뭐야?" → "너가 가상의 테이블 만들어서 예시로 설명해줘"를 물었을 때 생긴 세 문제를 고친다.
(a) 🤖 AI 설명이 문장 중간에 잘림
(b) 모델이 쓴 `#` 제목이 앱의 칸 제목보다 크게 보임
(c) 📄 칸이 "업로드한 자료에 관련 내용이 없습니다"로 나옴

## 결정과 근거 / Decisions & Why
- **원인 (a)**: `llm.chat`의 기본 `max_tokens=1500`. 추론형 모델은 `_call`이 `max_completion_tokens`로 다시 시도하는데, 이 한도에는 숨은 추론 토큰도 포함된다. `finish_reason`을 확인하지 않아서 잘려도 아무 표시가 없었다.
  - 수정: `llm.chat_with_status()`로 잘림 여부를 받는다(`chat()`의 시그니처는 그대로 유지해 기존 호출부는 바뀌지 않는다). 한도는 일반 설명 4000, 자료 2500으로 올렸다.
  - 잘리면 `answer.finish()`가 안내 문구를 붙인다. 코드 블록 중간에서 잘렸으면 펜스를 먼저 닫는다.
  - 프롬프트에 "표는 6행 이내, 간결하게, 끝까지 완결"을 추가했다.
- **원인 (b)**: 모델이 `#`·`##`를 씀.
  - 수정: 프롬프트로 제목을 금지하고, 그래도 쓰면 `demote_headings()`가 굵은 글씨로 바꾼다. 코드 블록 안은 건드리지 않는다(CommonMark 방식으로 펜스 문자·길이 추적).
- **원인 (c)**: 자료 검색(BM25)이 현재 질문만 썼다. 후속 질문에는 주제 단어가 없다.
  - 수정: `search_query()`가 직전 사용자 질문과 현재 질문을 합쳐 검색한다. NOTES 프롬프트 규칙 4는 후속 질문이면 앞 질문의 주제로 관련성을 판단하게 바꿨다.
- **교차검증과 출제 안내에는 잘림 안내 문구를 붙이기 전 원문(`grounded_raw`)을 넘긴다.** 안내 문구가 '주장'으로 판정되거나 검색어에 섞이지 않게 하려는 것이다.
- 버린 접근: 잘리면 자동으로 이어서 호출하기. 비용과 시간이 불확실해서, 사용자가 "이어서 설명해줘"라고 묻도록 안내만 한다.

```
Diff의 경계 조건과 실제 호출 응답 형태를 확인하겠습니다.

1. **Medium — 4개 이상의 백틱을 사용하는 코드 펜스가 깨질 수 있습니다.** `_FENCE`는 현재 여는/닫는 구분자 길이를 확인하지 않고 ` ``` ` 접두사만 토글합니다. 예를 들어 외부 펜스가 ` ````markdown `이고 내부에 ` ```python `가 있으면 내부 펜스에서 상태가 해제되어 이후 `#` 주석을 제목으로 오인해 변환할 수 있습니다. **수정:** 펜스 종류와 길이를 함께 추적하고, 닫는 펜스는 공백만 허용하도록 처리하세요.

2. **Medium — 잘림이 코드 블록이나 표 안에서 발생하면 안내 문구가 구문 밖으로 빠져나오지 못합니다.** `finish()`가 원문 뒤에 안내 문구만 추가하므로, 생성이 열린 코드 펜스나 표 행에서 중단된 경우 안내 문구가 코드 블록 또는 표에 포함될 수 있습니다. **수정:** 잘림 안내를 붙이기 전에 미닫힌 펜스를 닫고, 불완전한 표는 안내 문구와 분리하여 렌더링하세요.

3. **Low — 교차 출제용 검색 텍스트에 잘림 안내 문구까지 포함될 수 있습니다.** `grounded = finish(...)` 이후 `mapping_text(..., grounded)`를 호출하므로 안내 문구의 표현이 실제 자료 개념과 혼합되어 검색될 수 있습니다. **수정:** 교차 출제 매핑에도 잘림 안내를 붙이기 전 원문을 전달하세요.

**High 카테고리:** 별도 이슈 없음.

```
### 분류
1. 백틱 4개 이상 펜스 안의 ``` 를 닫는 펜스로 오인 → **반영함**. `_scan_fences`가 문자·길이·뒤 공백을 확인한다. 테스트 1개.
2. 코드 블록이나 표 중간에서 잘리면 안내 문구가 그 안에 갇힘 → **반영함**. 열린 펜스를 닫는다. 표는 빈 줄로 끝나므로 이미 분리된다. 테스트 2개.
3. 출제 안내 검색어에 안내 문구가 섞임 → **반영함**. `grounded_raw`를 넘긴다.

## 함정 / Gotchas
- 추론형 모델의 `max_completion_tokens`는 보이지 않는 추론 토큰을 포함한다. 한도를 낮추면 답이 비거나 잘린다.
- `llm.chat()`은 잘림 여부를 버린다. 잘림을 알아야 하는 곳은 `chat_with_status()`를 쓴다.
- `study.py`에서 `grounded`는 화면용(안내 문구 포함), `grounded_raw`는 검증·검색용이다.
